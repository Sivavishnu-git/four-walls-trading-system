STEP 1 — User clicks Login
Browser navigates to GET /api/auth/login. Proxy builds the Upstox authorise URL with client_id, redirect_uri, response_type=code and issues a 302 redirect.
STEP 2 — User approves on Upstox
Upstox shows a consent screen. On approval it calls back to GET /api/auth/callback?code=xxx on the proxy.
STEP 3 — Token exchange
Proxy POSTs the code + client_secret to Upstox token endpoint. Gets back an access_token (valid for the trading session).
STEP 4 — Token delivered to SPA
Proxy redirects browser to FRONTEND_URI?token=<access_token>. AuthContext strips the query param and stores the token in localStorage. All subsequent apiFetch calls inject Authorization: Bearer <token>.

⏱ 3-Minute OI Capture Cycle (browser-side)
1. Timer fires Aligned to 15:12 anchor. First tick captured immediately when Connect is pressed.
2. Snapshot built Reads latestDataRef.current → { oi, ltp, timestamp }. Computes Δ from session-open OI.
3. State + Storage setOiHistory() → React re-render. Saved to localStorage. Last 10 rows shown in table.
4. DB persist POST /api/oi/save with { ts, symbol, oi, ltp } → SQLite future_oi table. Fire-and-forget.
Fallback: useUpstoxPolling polls REST every 5 s when WebSocket is unavailable  ·  OI tracker on the server independently polls every 3 min via cron regardless of browser state

Calling the API from Python
Same /api/* endpoints work from any HTTP client — here with the requests library
REQUEST → proxy-server.js
import requests

BASE = "http://localhost:3000"
TOKEN = "your_upstox_access_token"

HEADERS = {
    "Authorization": f"Bearer {TOKEN}",
    "Content-Type": "application/json",
}

# ── 1. Get today's OI history ──────────────────
import datetime
today = datetime.date.today().isoformat()   # "2025-06-16"

resp = requests.get(
    f"{BASE}/api/oi/history",
    params={"date": today, "symbol": "NIFTY", "limit": 200},
    headers=HEADERS,
)
data = resp.json()["data"]   # list of OI rows

# ── 2. Save a custom OI snapshot ───────────────
payload = {
    "ts":     1718521800000,   # epoch ms
    "symbol": "NIFTY",
    "oi":     13_450_000,
    "ltp":    24320.50,
}
requests.post(
    f"{BASE}/api/oi/save",
    json=payload,
    headers=HEADERS,
)

# ── 3. Place an order (dry-run) ────────────────
order = {
    "instrument_token": "NSE_FO|51714",
    "transaction_type": "BUY",
    "quantity":         50,
    "product":          "MIS",
    "order_type":       "MARKET",
    "dry_run":          True,
}
requests.post(
    f"{BASE}/api/bot/order/start",
    json=order, headers=HEADERS,
)
